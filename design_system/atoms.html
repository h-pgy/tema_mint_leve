1. Átomos (Widgets Base GTK3 & xfwm4)

Padrões simples e diretos dos menores elementos visuais do sistema. Cada átomo indica sua implementação CSS no mock, quando deve ser usado e para qual seletor nativo do Linux Mint XFCE ele é portado.

Botões GTK3 (.ds-atom-btn)

GTK3: button
Quando usar: Ações de janelas de diálogo, botões do painel (variante --flat) e confirmações. Destino no OS: button, button.suggested-action, button.destructive-action, button.flat e button:disabled em ~/.config/gtk-3.0/gtk.css. 
<button class="ds-atom-btn ds-atom-btn--primary">Salvar</button>

Input / Entry (.ds-atom-entry)

GTK3: entry
Quando usar: Barra de busca do Whisker Menu, caixas de diálogo e paths do Thunar. Destino no OS: entry e entry:focus (usa box-shadow: inset sem alterar border-width para evitar layout jitter). 
<input class="ds-atom-entry is-focused" value="..." />

Controles de Janela (.ds-atom-win-ctrl)

xfwm4: *.xpm
Quando usar: Exclusivamente dentro da molécula de barra de título .ds-mol-xfwm-titlebar. Destino no OS: Bitmaps 12x12 em ~/.themes/<Tema>/xfwm4/{close,maximize,hide}-{active,inactive}.xpm. 
<span class="ds-atom-win-ctrl ds-atom-win-ctrl--close"></span>

Badges / Pager (.ds-atom-badge)

GTK3: .xfce4-panel
1: dev 2: web 3: docs BAT 96%
Quando usar: Indicadores de área de trabalho (Workspace Pager) e pílulas de status no painel. Destino no OS: #pager-button e widgets de status do xfce4-panel. 
<span class="ds-atom-badge ds-atom-badge--active">1: dev</span>

Switch GTK3 (.ds-atom-switch)

GTK3: switch
Quando usar: Telas de configuração GTK3 e toggles de energia/rede. Destino no OS: Nós switch, switch:checked e switch slider no gtk.css. 
<div class="ds-atom-switch ds-atom-switch--checked">
  <div class="ds-atom-switch__Knob"></div>
</div>

Separadores (.ds-atom-separator-*)

GTK3: separator
Item A Item B
Quando usar: Divisão sutil de grupos no xfce4-panel ou listas de menus. Destino no OS: Nó separator em ~/.config/gtk-3.0/gtk.css. 
<span class="ds-atom-separator-v"></span>
